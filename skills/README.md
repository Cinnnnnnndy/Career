## UX 设计目标制定（ux-goal-setting）

来源：UCD 中心 2026 年 UX 设计项目目标制定研讨会（To B / To C / To D 三场，2026-05-27～29）的原始目标、SMART 刷新版、会上修改版和评委点评。范例已脱敏：不含人名、工号，客户局点、产品名和品牌做了泛化。

内容结构：

1. 方法论：一条目标 = 场景与问题 → 设计策略与设计点 → 体验结果 → 落地 → 支撑业务
2. 评委反复强调的 14 条原则（设计策略而非功能、基线与量化、NSS 统一口径、时间点与局点、支撑/达成用词、交付沿途与创新分开、句式精简等）
3. 按项目场景调整：用户类型（To B / To C / To D）× 项目性质（首版本、改版、迭代、创新、AI、平台沉淀、内容型站点）
4. 表述方式：模板、常用动词、设计点“三连”语料、功能化 → 设计化对照、避免的写法
5. 写作步骤、自检清单、6 个“原始 → 评委点评 → 改写”范例、输出格式

使用：在 Claude 里保存为 skill 后，直接贴一段 UX 目标说“帮我诊断/改写”，或说“帮我写 xx 项目的 UX 目标”。

## 高老师视角材料审视（gao-review）

来源：Cindy 整理的三层领导高老师的核心关注点（战略与商业、汇报逻辑与材料质量、设计品质与竞争力、AI 时代的设计角色、项目管理与协同、设计师能力、用户研究报告七个方面）。

内容结构：

1. 七个审视维度：每个维度列“看什么 → 问题信号 → 高老师式追问”
2. 按材料类型（汇报 PPT、设计方案、用研报告、UX 目标/项目规划）调整各维度侧重
3. 审视步骤：识别材料 → 一句话复述 → 骨架检查 → 逐维度审 → 模拟追问 → 修改建议 → P0/P1/P2 排序
4. 输出格式（含“会上最可能被问的 5 个问题”和标题改写表）、常用改写对照
5. 与 ux-goal-setting 互相引用：目标写法细查交给 ux-goal-setting，领导视角审视交给本 skill

使用：在 Claude 里保存为 skill 后，贴上材料（或上传 PPT/PDF）说“用高老师视角帮我审一下”，或“快速过一遍”只看必改项和会上可能被问的问题。
